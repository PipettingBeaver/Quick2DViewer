# Quick2DViewer
HTML based tool for unbroken annotation viewing, search, and feature export allowing for both MPI's Quick2D and PDB input.

Quick2DViewer is available here: [https://pipettingbeaver.github.io/Quick2DViewer/](https://pipettingbeaver.github.io/Quick2DViewer/)

## Documentation

- `WORKFLOW.md` — the protein-characterization workflow the Evaluation Guide is
  built on: every step's purpose, why it matters, how to read the output, and
  DOI-verified citations. **Generated** from the app by
  `npm run doc:workflow` (`node tools/build-workflow-doc.js`); do not edit by hand.
- `DESIGN.md` — architecture decisions, roadmap and open items.
- `UX_GUIDELINES.md` — the design-pass checklist and UI conventions.
- `CHANGELOG.md` — release notes (also readable in-app via the version badge).
