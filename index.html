Options

Command Engine

Which tool's syntax the sidebar's Target/Command panel generates.

Annotation Colors

Choose a colour set for the annotation types (H/P/E/C/M/D) used in the heatmap cells, row badges, and legend. The colourblind-safe option follows the Okabe-Ito palette; high-contrast picks stronger tints for low-vision users.

Conservation Scoring

How the CONSERVATION row is computed (1 = fully conserved, 0 = fully divergent) from the variant FASTA sequences uploaded via Attach, and how those sequences are aligned onto the reference AA sequence. Changes apply to the heatmap row immediately and are saved with the session.

Annotation Offload (UniProt)

Pull curated residue-level annotations (domains, topology, active/binding sites, PTMs, variants) from UniProt and show them as rows in the viewer.

Accession looks up a known UniProt accession directly. Search finds an accession by gene, protein, or organism name first (fast). Sequence resolves the current sequence to an accession via BLAST (slow, ~5 min). Fetching requires a network connection and nothing is uploaded except the requested term/sequence/accession.

Topology (membrane)

Paste the output of a topology predictor (TMHMM segments like inside 1 11 / TMhelix 12 30, or a DeepTMHMM JSON) to add it as a per-residue inside / TM-helix / outside track. Add two or more sources to also get a majority-vote Consensus track.

Save File

Export the full current session - sequence, attached structures, selection, and preferences - as a portable .json file you can move to another browser or machine. To bring one back in, attach it via the toolbar's Attach Structure(s) or JSON button like any other file - Q2DV recognizes it automatically from a marker inside the file, without needing a separate import control.

This is a different, restorable format from the Data modal's "Raw JSON" export, which is a read-only report and can't be re-imported.

The save stays small because it never embeds the raw PDB/CIF text - it only references locally-attached files by hash. On the machine that created it, 3D models come right back from that device's structure cache; on another machine, Data > Structure Files lists which files need re-attaching (or use Find to locate them in a folder).

Cached Data

Your pasted Quick2D text, the pLDDT/RSA data derived from attached structure files, current selection, and view preferences are saved automatically in this browser (via localStorage) so they survive a page refresh or reopening this tab later. Nothing is uploaded anywhere - it never leaves your device.

Note: this session cache does NOT include the raw structure file text - that lives in the separate, device-local structure cache below, so "Reset Data" (which clears this session cache) won't delete your cached PDB/CIF copies.

Local Structure Cache (this device)

Raw PDB/CIF text you've attached is cached on this device (via IndexedDB) so 3D models reappear instantly after a refresh or a save re-import - never re-uploading the same file twice. It never leaves this device and is not embedded in exported saves, so a save taken to another machine will ask for its local files there (Data > Structure Files > Find to locate them). Old copies no longer referenced by the current session are automatically evicted, oldest-first, beyond the 100 MB soft cap.

Clearing this is separate from "Reset Data" above - use it only when you want to free up space without touching the data you have loaded.

Homolog Templates (HHpred)

Homologs imported from .hhr files, ranked by a template score (HHpred probability × identity × query coverage) — the top hit is the best candidate for structural/functional templating. Structure shows whether a matching PDB/CIF is already cached or auto-fetchable from RCSB.

Structure Files

Each PDB/CIF file is scanned on upload for a rough protein classification, apo/holo ligand state, and oligomeric state (chain count). This is best-effort: many files - especially computational models like AlphaFold predictions - simply don't record this information, in which case it's reported as such rather than guessed.
