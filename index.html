Command Engine

Which tool's syntax the sidebar's Target/Command panel generates. Support for more tools can be added later without any other UI changes.

Save File

Export the full current session - sequence, attached structures, selection, and preferences - as a portable .json file you can move to another browser or machine. To bring one back in, attach it via the toolbar's Attach Structure(s) or JSON button like any other file - Q2DV recognizes it automatically from a marker inside the file, without needing a separate import control.

This is a different, restorable format from the Data modal's "Raw JSON" export, which is a read-only report and can't be re-imported.

Cached Data

Your pasted Quick2D text, the pLDDT/RSA data derived from attached structure files, current selection, and view preferences are saved automatically in this browser (via localStorage) so they survive a page refresh or reopening this tab later. Nothing is uploaded anywhere - it never leaves your device.

Note: the raw structure file text itself isn't cached (only its derived confidence/exposure values, plus its name for reference) to keep the cache well under the browser's storage limit - re-attach a file after a refresh only if you need its original text again.
